# 光伏电站运行维护规程

## 1 适用范围
本规程适用于并网光伏电站（含集中式地面电站、工商业屋顶电站）的日常巡检、设备维护、故障处理与运行记录管理。

## 2 日常巡检
### 2.1 巡检频次
- 集中式电站：每日一次常规巡检，每月一次红外测温专项，每季度一次组件抽样 EL 检测。
- 屋顶分布式电站：每周一次常规巡检，每季度一次全面检查。
- 雨后、冰雹、沙尘等异常天气后须在 24 小时内完成专项巡检。

### 2.2 组件巡检要点
- 热斑：红外热成像检测，同一组件内电池片温差超过 20 摄氏度判定为异常热斑，需立即处理。
- 隐裂：通过 EL（电致发光）检测，隐裂面积超过单片面积 5% 的组件应列入更换清单。
- 积尘：组件表面积尘导致发电效率下降超过 3% 时应安排清洗，清洗宜在早晚或阴天进行，避免组件高温时冷水冲洗导致炸裂。
- 遮挡：检查周边杂草、树木、新增建筑物造成的阴影遮挡，遮挡会引发热斑与功率失配。
- 外观：检查玻璃破损、背板老化、边框变形、接线盒进水、MC4 接头烧蚀。

### 2.3 逆变器巡检要点
- 运行参数：直流输入电压、电流、交流输出功率、电网频率、机内温度。
- 告警信息：绝缘阻抗低（PV-ISO）、电网电压异常、过温降载、风扇故障。
- 异常处理：逆变器报绝缘阻抗故障时，应先排查直流侧线缆破损、接头进水、组件 PID 效应，禁止在未查明原因前反复合闸。
- 效率评估：逆变器转换效率长期低于 96% 时应安排检修。

### 2.4 汇流箱与线缆
- 检查防雷器状态窗口，变红须立即更换。
- 检查熔断器有无熔断、直流母线有无松动发热。
- 电缆桥架、穿管部位有无破损、鼠咬、进水。

## 3 常见故障与处理
### 3.1 组串电流为零
可能原因：熔断器熔断、MC4 接头脱落或烧蚀、组串线缆断路、组件大面积遮挡。
处理流程：先测量组串开路电压，电压为 0 判定为断路，电压正常但电流为 0 判定为接头或熔断器问题。

### 3.2 发电量偏低
排查顺序：
1. 对比同期辐照数据，排除天气因素。
2. 查看逆变器限功率记录，排查电网调度限发。
3. 逐组串测量电流，定位失配组串。
4. 检查组件积尘与遮挡。
5. 排查 PID（电势诱导衰减）效应，PID 可通过夜间反压修复装置部分恢复。

### 3.3 逆变器频繁启机
多为电网电压波动或绝缘阻抗检测未通过，应记录启机时段与电网电压曲线，必要时协调电网侧处理。

## 4 安全规定
- 直流侧检修必须先断开对应组串，验电确认无电压后作业。
- 雷雨天气禁止户外电气作业。
- 组件清洗、更换须使用绝缘工具并佩戴绝缘手套。
- 运维人员须持电工证上岗，高处作业须系安全带。

## 5 记录与指标
- 必填记录：巡检记录、缺陷台账、发电量日报、故障处理单、两票（工作票、操作票）。
- 核心指标：
  - PR（性能比）：并网光伏电站一般在 75% 至 85% 之间，低于 75% 需排查系统损耗。
  - 等效利用小时数：反映单位装机容量的发电能力。
  - 弃光率：弃光电量占理论发电量的比例。
  - 可利用率：统计期内机组可用时长占比，一般要求不低于 98%。
